# Image sets

Select 2–50 saved image cards in bulk edit and choose **Create image set**.
Set a title, choose the cover and arrange the images before saving. The set opens
in the same gallery as saved social posts, with thumbnails, keyboard navigation,
full-screen viewing and downloads of the originals.

**Edit image set** changes the order, cover or membership. Removing an image
returns its original card to the feed. **Dissolve set** restores all the original
cards; the confirmation explains that the set's own title, notes and tags are
removed. Original files, source links, metadata and previous AI results remain.

Sets are private and currently accept individual image cards only. A card belongs
to at most one set; nested sets and videos are not supported. Shared-list images
must be removed from sharing first. Ready imported images can be grouped while
catalog analysis is still held. Original cards keep their IDs and remain available
through links inside the set. Remove a member from its set before editing or
deleting that original. Private list placement and initial tags are copied to the
new set, while the originals retain their memberships and tags.

A set uses the combined Sensitive assessment of its members. Choosing a safe cover
does not reveal a sensitive or unclassified image. Existing Work, Balanced and
Show all visibility rules continue to apply.

AI analysis is explicitly on hold for sets and their members in this first
version. Creating or editing a set does not make LLM calls. Existing results stay
on the originals. Composition-aware group analysis and similarity suggestions
are separate future steps; no set is automatically dissolved or merged by AI.
